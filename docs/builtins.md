## Navigation Commands 
1. gyatt - Change directory✔
2. gyatt.. - move to the parent dir✔
3. &gyatt - navigate to the global directories✔
2. whereami - Show current directory ✔
3. ls -  same as dir (list the files)✔

## shell inforamtion
1. cooked - same as help (show all the built-in commands)
2. mog - same as clear (clear terminal)✔
3. vibe - version ✔
4. about - same as the about 

## miscellaneous commands
1. skedaddle or exit - exit✔
